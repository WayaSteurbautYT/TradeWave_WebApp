# TradeWave Roadmap

## Phase 1 — Stabilize the MVP (highest priority)
### Goal
Ship a usable beta with a confident, stable onboarding and marketplace loop.

### Focus
- Auth and user profile flows
- Core onboarding and role selection
- Marketplace listing and browsing
- Basic payment integration in sandbox mode
- Improved dashboard and navigation
- Bug cleanup and state stabilization

## Phase 2 — Beta polish and contributor readiness
### Goal
Make the project easier for other people to continue.

### Focus
- Improve README and setup docs
- Add issue templates and PR templates
- Add a handoff package and architecture notes
- Clean repo structure and keep legacy docs in one place
- Add design showcase and branding assets
- Confirm production deploy instructions and environment alignment

## Phase 3 — Product depth
### Goal
Expand the platform beyond the minimal beta.

### Focus
- Real bidding or hiring workflow improvements
- Creator analytics and dashboards
- AI-enhanced support and recommendation features
- Better escrow, payout, and finance handling
- Admin tooling and moderation flow

## Phase 4 — Growth and scaling
### Goal
Prepare the platform for a broader user base.

### Focus
- Performance optimization
- Better monitoring and observability
- Role-based permissions
- Feature flags for experiments
- Additional payment support and scaling notes

## Prioritization recommendation
If you want this to launch well, the priority order should be:
1. Core auth and user profile
2. Marketplace / project posting and hiring
3. Payment flow and transaction review
4. Beta polish and deployment docs
5. AI features and advanced analytics
6. Optional scale features

## Outcome target
A clean beta launch is achieved when the app can be used by a small user group, feedback is being collected, and the repo and ownership docs are prepared for continued work by team members or outside contributors under the agreed commercial-use restrictions.
