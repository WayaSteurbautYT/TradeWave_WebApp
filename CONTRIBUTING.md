- You are responsible for ensuring your contribution does not infringe on third-party rights.
- Commercial reuse of the project or derived works without written permission is not allowed.

Contribution workflow
1. Fork the repository.
2. Create a topic branch with a clear name.
3. Keep the scope focused and well described.
4. Run relevant tests and validation checks locally.
5. Open a pull request with a clear summary and screenshots or a short video if the change affects UI.

Before merging
- Do not commit secrets or production credentials.
- Prefer clear commit messages and small, reviewable changes.
- Add or update tests where relevant.
- Include documentation for any user-facing changes.
